# lcg-c1-2627-g04
*A 2D platformer & side-scrolling game about Madama Goody and gender equality.*

This project is a university assignment for the **Computer Graphics / Game Design** course.
It is a small browser game built with [Phaser 3](https://phaser.io/) and the **[PoliPhaser](https://github.com/HEAPLab/poliphaser)** wrapper library
(both included in the `lib/` folder).

## About the game

The game combines two things:

- **The story of Madama Goody**, the main character, who guides the player through the rooms of the game. ([read full story here](https://fairytalez.com/fairy-ointment/))
- **Goal 5 of the UN 2030 Agenda – Gender Equality** ([read more](https://sdgs.un.org/goals/goal5)),
  which aims to achieve gender equality and empower all women and girls.

The player explores a corridor and a bedroom (which exists in a colour version and a black-and-white version)
and moves between them through doors.
